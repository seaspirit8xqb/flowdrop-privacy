FlowDrop Privacy Policy

Last updated: September 22, 2026

FlowDrop — Local File Sharing is a Windows application that helps users transfer files directly between devices on the same local network.

Files and folders

Files that you send, receive, preview, stream, or share through FlowDrop are transferred directly between your Windows PC and the nearby device using your local network. FlowDrop does not upload file contents to a FlowDrop cloud service.

Local history and settings

FlowDrop stores settings, transfer history, file names, transfer direction, timestamps, byte counts, transfer status, and the local-network address of connecting devices on your Windows PC. This information is stored locally and can be cleared by the user.

Google Sign-In

Google Sign-In is optional. When enabled, FlowDrop requests only the OpenID Connect scopes required for basic identity: openid, email, and profile. FlowDrop does not request permission to read or send Gmail messages.

The Google profile may include an account identifier, display name, email address, and profile-picture URL. The profile is cached locally on the Windows PC. If Google provides a refresh token, FlowDrop stores it in Windows Credential Locker. Signing out removes the locally cached profile and stored refresh token.

Network operation and security

FlowDrop runs a local HTTP service so nearby devices can open share links in a browser. Share links contain random tokens and may optionally require a PIN. Users should use FlowDrop only on networks they trust.

File transfers in this release are limited to the local network and do not use HTTPS encryption. Users should avoid sharing sensitive files on untrusted networks.

Advertising and sale of information

FlowDrop does not include advertising, cross-app tracking, or the sale of personal information.

Third-party services

If the user enables Google Sign-In, Google processes authentication information according to Google's privacy policy. FlowDrop does not use Google Sign-In to access Gmail messages.

Children's privacy

FlowDrop is not directed to children under the age of 13 and does not knowingly collect personal information from children.

Changes to this policy

This policy may be updated when FlowDrop adds or changes features that affect privacy. The latest version will be published on this page.
