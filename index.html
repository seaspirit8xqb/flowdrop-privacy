FlowDrop Privacy Policy

Last updated: September 22, 2026

FlowDrop — Local File Sharing is a Windows application that helps users transfer files directly between devices on the same local network.

Files and folders

Files that you send, receive, preview, stream, or share through FlowDrop are transferred directly between your Windows PC and the nearby device using the local network.

FlowDrop does not upload file contents to a FlowDrop-operated cloud service. File contents are shared only when the user intentionally creates a share or starts a transfer.

Local history and settings

FlowDrop stores application settings and transfer metadata locally on the Windows PC. Transfer history may include file names, transfer direction, timestamps, byte counts, transfer status, and the local network address of a connecting device.

This information is stored locally. Users can clear transfer history from the application. FlowDrop does not sell this information or use it for cross-application tracking.

Google Sign-In

Google Sign-In is optional. When enabled, FlowDrop requests only the OpenID Connect scopes required for basic identity: openid, email, and profile.

FlowDrop does not request permission to read, send, or manage Gmail messages.

The Google profile may include an account identifier, display name, email address, and profile-picture URL. The profile is cached locally on the Windows PC.

If Google provides a refresh token, FlowDrop stores it in Windows Credential Locker. Signing out removes the locally cached profile and stored refresh token from the PC.

Google processes authentication information according to its own privacy policy: Google Privacy Policy

Network operation and security

FlowDrop runs a local HTTP service so nearby devices can open share links in a browser. Share links contain random tokens and may optionally require a PIN.

FlowDrop is designed for use on trusted local networks. Users should avoid sharing sensitive files on networks they do not trust.

File transfers in this release are limited to the local network and do not use HTTPS encryption for local file payloads. Users are responsible for choosing an appropriate network and enabling PIN protection when needed.

Information sharing

File data is sent directly between the Windows PC and the nearby device participating in the user's share or transfer session.

When Google Sign-In is enabled, authentication and profile information is processed by Google as necessary to authenticate the user. FlowDrop does not share file contents with Google.

Advertising and sale of information

FlowDrop does not include advertising, cross-app tracking, or the sale of personal information.

Children's privacy

FlowDrop is not directed to children under the age of 13 and does not knowingly collect personal information from children.

Changes to this policy

This policy may be updated when FlowDrop adds or changes features that affect privacy. The latest version will be published on this page.

Contact

For privacy questions or support, contact: flowdrop.support@gmail.com
